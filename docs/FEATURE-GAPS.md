# Trove 功能差距分析（对标同类软件）

> 调研日期：2026-09-08 ｜ 最近更新：2026-09-08（标记第六批已实现项）｜ 适用版本：Trove 0.3.0
>
> 本文取代已删除的 `FRONTEND-GAPS.md`（前后端对照清单）。它回答一个问题：
> **与市面上的素材管理软件相比，Trove 还缺什么。**
>
> 优先级定义：
> - **P0** 核心体验缺口，用户第一天就会撞上；本次迭代实现
> - **P1** 高价值，下一两个迭代应补齐
> - **P2** 有明显需求但工程量大，进路线图
> - **P3** 长尾/存疑，暂不规划

## 二、Trove 现有能力（截至 0.3.0）

内容寻址去重导入（SHA-256）、集合树（多对多、拖拽改父级）、智能集合（JSON 规则树：kind/评分/收藏/标签/文本/扩展名/大小/主色/色标/拍摄日期/宽高比/方向）、标签（层级、大小写不敏感、颜色）、收藏、1–5 评分、FTS 全文搜索（标题/描述/标签名）、视觉搜索（pHash + 颜色直方图 + 按颜色）、CLIP 语义搜索（英文 ViT-B/32）、回收站（还原/彻底删除/孤儿清理）、多选与浮动工具栏、拖拽导入与打标、Inspector 行内编辑、网格/列表视图与排序、按颜色/类型/收藏筛选、最近查看历史、撤销/重做、维护工具（缩略图重建/索引重建/孤儿清理/SHA-256 完整性校验）、自动备份、库统计、批量重命名、来源文件夹面板、URL 导入、链接原文件导入、库热切换、元数据 JSON 导出与媒体包、中英双语、字体元数据与实况预览、EXIF/音频标签/MP4 挖掘、RAW/HEIC/SVG/PSD 缩略图、系统 ffmpeg 视频海报、本地采集服务与浏览器扩展。

**一句话总结：组织与检索内核已接近同类产品水准，收集入口基本补齐；缺口集中在「文件格式补全、批处理出口、AI 自动化、时间线视图」几条线上。**

## 四点六、第六批实现（2026-09-08 夜 + 续）

| 功能 | 说明 |
|---|---|
| 链接文件重连 | 链接资产原文件被移动/删除后：Inspector 位置行显示红色「文件丢失」徽标 + 重新链接按钮（RotateCw 图标）→ 系统文件选择器选新路径 → 核心校验（必须是链接资产、路径存在、SHA-256 与导入记录一致）→ 重写 `extra.source_path`；内容不符（想换文件请重新导入）、非链接资产、路径无效都会被拒绝并提示 |
| 动图播放 | GIF / 动态 WebP：gpui 资产系统从原文件解码全部帧原生播放（详细查看弹窗 + Inspector 预览）；APNG：gpui 只渲染 PNG 首帧，故用 image `PngDecoder::apng()` 拆帧 → RGBA→BGRA → 多帧 `RenderImage`（解码带 256MB 帧预算，超限回退静态），按路径全局缓存（含负缓存、容量上限 16）；缩略图仍静态，网格/列表性能不受影响 |
| 字体网格实况预览 | 导入时用 fontdue 光栅化生成 512×256「样张卡片」缩略图（白底黑字、样张以字体实况渲染、缺字跳过、词间空隙保持），作为字体资产在网格/列表/预览的封面；样张文本在设置 ▸ 通用可自定义，改样张后用维护页「重建缩略图（强制）」刷新（缩略图重建计划已覆盖字体） |
| 字体集合与系统安装 | 左栏新增「字体」系统视图（kind=Font 的实时计数与浏览，即全部字体的快捷入口）；Inspector 字体区支持**安装到系统**（Linux 复制到 `~/.local/share/fonts/trove/<sha>.<ext>` / macOS 用户字体目录，随后 `fc-cache -f` 刷新）与**卸载**，按内容哈希命名即天然的已安装状态检测（显示「已安装到系统」徽标）；仅对 Linux/macOS 生效，其他平台提示不支持 |
