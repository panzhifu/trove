# 交互系统 (Interaction System)

> 三视图布局、工作区、检查器、资源管理器、对话框 — UI 交互全解

---

## 概述

Trove 采用**停靠布局**（Dock Layout），将界面划分为多个功能面板：

```
┌─────────────────────────────────────────────────────────────┐
│                      标题栏 (Title Bar)                      │
│  File ▸  │  Settings ▸  │              窗口控制             │
├──────────┴──────────────┴───────────────────────────────────┤
│          │                              │                   │
│  资源管理器 │        工作区 (Workspace)      │    检查器        │
│  Explorer │                              │   Inspector      │
│          │   对齐缩略图网格 / 列表 / 时间线    │                  │
│  - 收藏夹  │                              │   - 缩略图       │
│  - 智能集合│                              │   - 标签         │
│  - 最近查看│                              │   - 色板         │
│  - 回收站  │                              │   - 属性         │
│          │                              │   - 编辑工具      │
│          ├──────────────────────────────┤                   │
│          │   批量操作工具栏 (选中时显示)     │                   │
├──────────┴──────────────────────────────┴───────────────────┤
│                      状态栏 (Status Bar)                     │
│  选中 3/120  │  📥 导入中... 123/456  │  存储 12.3 GB       │
└─────────────────────────────────────────────────────────────┘
```

---

## 工作区 (Workspace)

### 三种视图

| 视图 | 说明 | 适用场景 |
|------|------|---------|
| 网格 (Grid) | 对齐缩略图网格 | 浏览图片为主 |
| 列表 (List) | 详细信息表格 | 查看元数据 |
| 时间线 (Timeline) | 按时间分组 | 按拍摄时间浏览 |

### 网格视图

#### 对齐布局

- 统一行高，可变列宽
- 根据宽高比自动调整
- 密度滑杆调节

#### 选择操作

| 操作 | 说明 |
|------|------|
| 单击 | 单选 |
| Shift+单击 | 范围选择 |
| Ctrl+单击 | 多选切换 |
| Ctrl+A | 全选 |
| 拖拽框选 | 矩形区域选择 |

#### 上下文菜单

右键资产显示菜单：

```
打开
在新窗口打开
在文件夹中显示
────────────
收藏
评分 ▸ ★☆☆☆☆ / ★★☆☆☆ / ...
标签 ▸ ...
添加到合集 ▸ ...
────────────
复制
复制为路径
编辑 ▸ 旋转 / 翻转 / 裁剪
导出 ▸ ...
────────────
移到回收站
```

### 列表视图

#### 列定义

| 列 | 说明 |
|----|------|
| 名称 | 文件名 + 标题 |
| 类型 | 资产类型 |
| 尺寸 | 宽×高 |
| 大小 | 文件大小 |
| 评分 | 星级 |
| 标签 | 标签列表 |
| 日期 | 拍摄/创建时间 |

#### 排序

- 点击列标题排序
- 支持升序/降序切换
- 多列组合排序

### 时间线视图

#### 分组策略

| 粒度 | 说明 |
|------|------|
| 年 | 最粗粒度 |
| 月 | 默认粒度 |
| 周 | 中等粒度 |
| 日 | 最细粒度 |

#### 时间线标题

```
2026
├── 一月 (1,234)
│   ├── 第一周 (156)
│   └── 第二周 (189)
└── 二月 (987)
```

## 检查器 (Inspector)

### 面板组成

```
┌─────────────────────────────┐
│        缩略图预览            │
│    (点击放大 / 快速编辑)     │
├─────────────────────────────┤
│  标题: [____________]        │
│  描述: [____________]        │
│  来源: [____________]        │
│  评分: ★★★★☆               │
├─────────────────────────────┤
│  标签: [+添加标签]           │
│  🏷️ 风景 🏷️ 日落            │
├─────────────────────────────┤
│  色板: ■■■■■■               │
├─────────────────────────────┤
│  属性                        │
│  类型: PNG                   │
│  尺寸: 3000×2000             │
│  大小: 2.3 MB                │
│  SHA: abc123...             │
│  路径: ~/Photos/IMG_001.png  │
│         [定位源文件]          │
└─────────────────────────────┘
```

### 快速编辑

缩略图上的快捷按钮：

| 按钮 | 功能 |
|------|------|
| ↻ | 顺时针旋转 90° |
| ↺ | 逆时针旋转 90° |
| ↔ | 水平翻转 |
| ↕ | 垂直翻转 |
| ✎ | 打开编辑对话框 |

### 字体操作

字体资产特有：

| 操作 | 说明 |
|------|------|
| 安装字体 | 安装到系统 |
| 卸载字体 | 从系统移除 |
| 复制字体文件 | 复制到剪贴板 |

## 资源管理器 (Explorer)

### 树形结构

```
📁 收藏夹
├── ⭐ 收藏
├── 🕐 最近查看 (200)
└── 🗑️ 回收站

📁 智能集合
├── 📸 精选图片 (45)
│   └── rating >= 4 AND kind = image
├── 🎬 竖屏视频 (12)
└── 🏷️ 未标记 (89)

📁 合集
├── 🎁 项目A (23)
│   └── 子合集 (5)
├── 🌅 风景摄影 (156)
└── 📦 归档 (340)
```

### 拖拽操作

| 操作 | 说明 |
|------|------|
| 资产 → 合集 | 添加到合集 |
| 资产 → 标签 | 添加标签 |
| 合集 → 合集 | 改变父级 |
| 文件 → 资源管理器 | 导入文件 |

### 上下文菜单

```
新建合集
新建智能集合
────────────
重命名
删除
设置封面
────────────
导出
导入
```

## 标题栏 (Title Bar)

### 菜单

#### File 菜单

| 项 | 功能 |
|----|------|
| 打开文件... | 文件选择器 |
| 打开文件夹... | 文件夹选择器 |
| 从 URL 导入... | URL 下载入库 |
| 截图... | 屏幕截图入库 |
| 导入备份... | 从备份恢复 |
| 导出备份压缩包... | 整包备份 |
| 退出 | 关闭应用 |

#### Settings 菜单

| 项 | 功能 |
|----|------|
| 通用 | 通用设置 |
| 文件 | 文件设置 |
| 搜索 | 搜索设置 |
| 快捷键 | 快捷键绑定 |
| 插件 | 插件管理 |
| 关于 | 版本信息 |

### 搜索框

- 标题栏右侧搜索框
- 实时搜索，输入即搜
- 支持高级语法：`tag:风景 rating:>3`

## 状态栏 (StatusBar)

### 显示内容

| 区域 | 内容 |
|------|------|
| 左 | 选中计数（3/120） |
| 中 | 任务进度（可点击展开） |
| 右 | 存储占用、版本号 |

### 任务进度条

```
📥 导入中...  123/456  [取消]
🔄 AI 嵌入...  78/200   [取消]
```

- 点击展开任务列表
- 每个任务可单独取消
- 完成后自动消失

## 对话框 (Dialogs)

### 通用对话框

| 对话框 | 触发 | 说明 |
|--------|------|------|
| 重命名 | F2 / 双击名称 | 单资产重命名 |
| 编辑 | 选中 → 编辑 | 批量像素编辑 |
| 转换 | 选中 → 转换 | 批量格式转换 |
| 重复文件 | 工具 → 查找重复 | 重复图片管理 |
| 规则 | 工具 → 规则 | 自动化规则 |
| 设置 | Ctrl+, | 应用设置 |

### 编辑对话框

```
┌─────────────────────────────────────────┐
│  批量编辑 (3 张图片)                     │
├─────────────────────────────────────────┤
│  旋转:  [无] [90°↻] [180°] [90°↺]     │
│  翻转:  [水平] [垂直]                   │
│  裁剪:  [启用]                           │
│    上: [___]  下: [___]                 │
│    左: [___]  右: [___]                 │
│  质量: [────●────] 85                   │
├─────────────────────────────────────────┤
│  ⚠️ 包含 1 个链接文件，编辑将写回原文件   │
├─────────────────────────────────────────┤
│              [取消]  [应用]              │

```

```
┌─────────────────────────────────────────┐
│  自动化规则                              │
```

## 多窗口支持

### 窗口类型

| 类型 | 说明 |
|------|------|
| 主窗口 | 完整界面 |
| 预览窗口 | 独立预览（可多开） |
| 全屏预览 | 独占全屏 |

### 窗口间通信

- 预览窗口与主窗口同步
- 收藏/标签操作实时反映

---

## 剪贴板

### 支持格式

| 格式 | 操作 |
|------|------|
| PNG 图片 | 复制 → 粘贴导入 |
| 文件路径 | 复制 → 导入 |
| 文本 URL | 复制 → URL 导入 |

### 系统剪贴板

- `Ctrl+C`：复制选中的图片
- `Ctrl+Shift+V`：粘贴剪贴板图片入库
- 支持从浏览器/聊天软件直接粘贴
