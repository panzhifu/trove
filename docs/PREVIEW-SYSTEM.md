# 预览系统 (Preview System)

> 多格式素材即时预览 — 图片、视频、音频、3D 模型、字体、动图

---

## 概述

Trove 内置多格式预览渲染器，覆盖创作工作流中的主流文件格式。所有预览在本地完成，无需上传或外部服务。

| 预览类型 | 驱动 | 关键特性 |
|---------|------|---------|
| 图片 | image crate / resvg / jxl-oxide | 高清缩放、色板、直方图、EXIF |
| 视频 | ffmpeg + rodio | 音画同步、倍速、跳转、截图 |
| 音频 | ffmpeg + rodio | 波形图、频谱分析 |
| 3D 模型 | wgpu + 自研解析器 | GPU 渲染、旋转/缩放/平移 |
| 字体 | fontdue | 样张卡片、安装/卸载 |
| 动图 | image crate 逐帧 | GIF/WebP/APNG 播放 |

---

## 图片预览

### 支持的格式

| 格式 | 解码方式 | 备注 |
|------|---------|------|
| PNG | image crate | 标准解码 |
| JPEG | image crate | 标准解码 |
| WebP | image crate | 含动画 |
| AVIF | image crate | 需系统解码器 |
| TIFF | image crate | 多页支持 |
| SVG | resvg/usvg | 矢量渲染 |
| PSD | psd crate | 合成预览 |
| HEIC | 系统 heif-dec | 原生解码 |
| JXL | jxl-oxide | JPEG-XL 解码 |
| RAW | rawler | 去马赛克 → 白平衡 → sRGB |

### 预览功能

- **高清缩放**：最小/最大缩放倍率可配置
- **色板分布**：可视化色彩构成
- **直方图**：亮度/色彩分布统计
- **EXIF 元数据**：相机参数、GPS、拍摄时间
- **快捷编辑**：标题栏单图旋转/翻转

### 动图播放

- GIF / 动态 WebP / APNG 在预览与检查器中逐帧播放
- 网格缩略图保持静态以保证性能

## 视频预览

### 支持的格式

MP4、MOV、MKV、WebM（需 ffmpeg）

### 播放架构

```
┌─────────────────────────────────────────────┐
│                 App 层                       │
│  ┌──────────────┐     ┌──────────────────┐  │
│  │ 主区域播放器  │     │ 全屏播放器       │  │
│  └──────┬───────┘     └────────┬─────────┘  │
├─────────┼──────────────────────┼────────────┤
│         │    Preview Engine   │            │
│  ┌──────▼──────────────────────▼─────────┐  │
│  │         VideoEngine (ffmpeg)          │  │
│  │  - 逐帧解码 (video pipe)              │  │
│  │  - 音频管线 (rodio PCM 输出)          │  │
│  │  - 音频时钟同步                       │  │
│  └──────────────────────────────────────┘  │
├─────────────────────────────────────────────┤
│  AudioEngine (独立于窗口)                   │
│  - 全屏切换不中断音频                       │
└─────────────────────────────────────────────┘
```

### 功能特性

| 功能 | 说明 |
|------|------|
| 播放/暂停 | 空格键控制 |
| 时间线拖拽 | 精确跳转 |
| 倍速播放 | 9 档 0.25× – 4×，音调保持（`preview/transport.rs` 的 `SPEEDS`，视频与音频共用） |
| 音量控制 | 滑块 + 静音切换 |
| 音画同步 | 走音频时钟 |
| 截当前帧入库 | 播放头那一帧按**源尺寸**存成 PNG 资产（一次 ffmpeg，落 `incoming/` 后按链接导入，与截图同一条链）。刻意不取屏幕上那块已解码缓冲：播放器只为流畅拖动把帧限制在 720 宽，一张要留下的图不该继承播放预算 |

### 音频引擎设计

- **独立于窗口**：全屏切换时不中断音频
- **单一 sink**：所有窗口共享同一音频输出
- **ffmpeg 解码**：44.1 kHz 立体声 PCM 输出
- **rodio 播放**：低延迟音频输出

## 音频预览

### 支持的格式

MP3、WAV、FLAC、AAC、OGG、M4A、Opus

### 功能特性

- **播放器**：与视频共用 `preview/transport.rs` 那一套控件（播放/暂停、9 档倍速、音量），引擎是同一个 `AudioEngine`——它本来就只吃一个文件路径
- **波形带**：预览上一条 400 桶的包络，**可以拖**——按下/拖动移动播放头，松手才真正 seek（与滑块走同一个 `scrub_to`，所以两处不会为"现在在哪"打架）
- **波形卡片**：没有内嵌封面时用同一条包络画一张 512×288 的卡；有内嵌封面时优先封面（跳过 APIC 类型 1/2 的文件图标）
- **标签**：艺术家/专辑/时长进检查器属性页；`artist`/`album` **还没进全文索引**（那要 `INDEX_VERSION` 升版，见 [GAP-TO-SERPENT.md](./GAP-TO-SERPENT.md) 的 P2b）

包络是**首次播放时**算的（一次 ffmpeg、300 Hz 单声道），缓存在 `<cache>/libraries/<slug>/waveforms/`；导入热路径绝不为它起进程。没有频谱分析这一层——那是 Serpent 的说法，Trove 这边只有峰值包络。

## 文本预览

### 支持的格式

单一清单在 `trove-core/src/media/text.rs::is_text_ext`：纯文本与标记（`.txt` `.md` `.rst` `.tex`）、数据与配置（`.json` `.csv` `.yaml` `.toml` `.ini` `.xml` `.html` `.plist` `.xmp`）、样式与源码（`.css` `.js` `.ts` `.py` `.rs` `.go` `.c` `.h` `.glsl` `.wgsl` …）、着色器与字幕与联系人（`.srt` `.vtt` `.ics`）。**不含** `.svg`（那是图片）与 `.pdf`（读不了）。

### 功能特性

- **只读查看器**：gpui-kit 的 `Editor` 元素（行号槽、虚拟行、选择与复制都是它自带的），不是自己画一份
- **编码探测**：BOM → UTF-16 的 NUL 奇偶 → 二进制判定（NUL >2%）→ 严格 UTF-8 → `chardetng` 统计猜测（gb18030 / big5 / shift_jis / euc-kr / windows-1252 …），头部会写明这个文件被当成什么编码读的
- **1 MiB 上限**：截断是**说出来**的，不是藏起来的；因为一个能写回文件的界面如果不知道屏上只是开头，就会把开头覆盖回源文件——所以这里干脆不给写
- **文本卡片**：网格里的文本资产画的是它自己的前 11 行（走 SVG 光栅那条路，系统字体带 fallback，中文不会变成豆腐块）

## 卡片悬停：同时只有一张卡是活的

网格其余部分是恒静态的：上百张缩略图都不动，行布局还是冻住的，重绘不重量一遍。`components/preview/hover.rs` 是唯一的例外，而让它保持诚实的是预算：**同一时刻只有一张卡**，而且要指针在它上面**定住 500ms** 才开始——所以扫过一库素材什么都不起。

| 项 | 做法 |
|------|------|
| 状态在哪 | `WorkspacePanel` 持一个 `Entity<HoverCards>` 并 `observe` 它。**不在 controller**：那边 `cx.notify()` 会把所有观察库的面板一起惊动 |
| 视频 | `FramePipe` 解码，**320 宽**（播放器是 720——一张卡不该占播放预算）。解码环不借 `App`，帧丢进 mailbox，UI 侧 60ms 一次 presenter 取走；EOF 必须把管丢掉重开，否则读 `None` 空转烧一个核 |
| 音频 | 同一条通道起播 `AudioEngine`；指针离开即停（丢掉实体就是停声） |
| 卡内移动 | 位移超过宽度 2% 算 seek，**画面与声音一起 `restart_at`**——只跳画面会让整段音画错开 |
| 与 Serpent 的差别 | 它是"移动定帧、静止翻转成播放"两态；我们一态跟指针走。gpui 每次 seek 要重启一个 ffmpeg 进程，两态来回会抖 |
| 开关 | `settings.hover_media`（默认开，外观 ▸ 网格）。这是本应用唯一一件会发出声音的默认行为，所以它必须有一个能关的地方 |

## AI 分析的接触表

视频问模型"这段里有什么"时，发出去的不是一张海报帧，而是**一张 16 格、每格打上自己时间戳的 JPEG**（`media/video.rs::write_contact_sheet`：`fps=16/时长` + `scale=256:-2` + `tile=4x4` + `drawtext`）。

- **成本放在分析侧而不是导入侧**：一次 ffmpeg 只为真正被问过的那段素材付
- **按内容哈希缓存**在 `<cache>/libraries/<slug>/contact-sheet/<sha>.jpg`，同库重跑免费；这个目录登记在清理孤儿（`sheets_removed`）、容量报告的 `cache()` 与 `trove paths` 里
- **时间戳是重点也是软肋**：`drawtext` 需要字体提供者，某些 ffmpeg 构建没有，所以失败会退化成不带时间戳的一张表。这个退化是静默的，因此有一条测试单独跑带时间戳的那条链——转义写错不会让运行失败，只会让模型答不出"什么时候"

| STL | 自研解析器 | 3D 打印格式 |

| GLB | gltf crate | 二进制容器 |
| .blend | Blender 无头导出 | 转 GLB 后预览 |

### GPU 视口

```
┌─────────────────────────────────────────┐
│              wgpu 渲染                  │
│  ┌───────────────────────────────────┐  │
│  │  Lambert + Blinn-Phong 着色       │  │
│  │  眼罩光照 (EDL)                   │  │
│  │  背面剔除 + 补洞                  │  │
│  └───────────────────────────────────┘  │
│  ┌───────────────────────────────────┐  │
│  │  交互：旋转 / 缩放 / 平移          │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

### 大文件处理

| 技术 | 说明 |
|------|------|
| 流式常驻预算 | 20GB 不 OOM |
| 抽稀采样 | 覆盖度保持 |
| Meshlet 聚类 | 大网格 (≥8192 面) GPU 逐簇剔除 |
| 空间索引 | 可选 `.trovecloud` 离线索引 (9B/点, 60% 体积) |

### 降级策略

- 有 GPU → wgpu 硬件渲染
- 无 GPU → CPU 软件光栅器

## 缩略图缓存

### 存储布局

```
<cache_root>/
└── thumbs/
    └── <sha[:2]>/
        └── <sha>.jpg
```

### 缓存策略

- 纯内容派生 → 安全删除重建
- 按 BLAKE3 内容哈希分桶（`thumbs/<sha[:2]>/<sha>.jpg`）→ 避免单目录文件过多
- 导入时检查缓存 → 跳过已存在

### 缩略图类型

| 资产类型 | 生成方式 |
|---------|---------|
| 图片 | 降采样至 512px |
| 视频 | ffmpeg 提取海报帧 |
| 字体 | 渲染样张卡片 (512×256) |
| 3D | 渲染模型正交视图 |
