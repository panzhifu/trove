# 预览系统 (Preview System)

> 多格式素材即时预览 — 图片、视频、音频、3D 模型、字体、动图

---

## 概述

Trove 内置多格式预览渲染器，覆盖创作工作流中的主流文件格式。所有预览在本地完成，无需上传或外部服务。

| 预览类型 | 驱动 | 关键特性 |
|---------|------|---------|
| 图片 | image crate / resvg / jxl-oxide | 高清缩放、色板、直方图、EXIF |
| 视频 | ffmpeg + rodio | 音画同步、倍速、跳转、截图 |
| 音频 | ffmpeg + rodio | 波形图、频谱分析 |
| 3D 模型 | wgpu + 自研解析器 | GPU 渲染、旋转/缩放/平移 |
| 字体 | fontdue | 样张卡片、安装/卸载 |
| 动图 | image crate 逐帧 | GIF/WebP/APNG 播放 |

---

## 图片预览

### 支持的格式

| 格式 | 解码方式 | 备注 |
|------|---------|------|
| PNG | image crate | 标准解码 |
| JPEG | image crate | 标准解码 |
| WebP | image crate | 含动画 |
| AVIF | image crate | 需系统解码器 |
| TIFF | image crate | 多页支持 |
| SVG | resvg/usvg | 矢量渲染 |
| PSD | psd crate | 合成预览 |
| HEIC | 系统 heif-dec | 原生解码 |
| JXL | jxl-oxide | JPEG-XL 解码 |
| RAW | rawler | 去马赛克 → 白平衡 → sRGB |

### 预览功能

- **高清缩放**：最小/最大缩放倍率可配置
- **色板分布**：可视化色彩构成
- **直方图**：亮度/色彩分布统计
- **EXIF 元数据**：相机参数、GPS、拍摄时间
- **快捷编辑**：标题栏单图旋转/翻转

### 动图播放

- GIF / 动态 WebP / APNG 在预览与检查器中逐帧播放
- 网格缩略图保持静态以保证性能

## 视频预览

### 支持的格式

MP4、MOV、MKV、WebM（需 ffmpeg）

### 播放架构

```
┌─────────────────────────────────────────────┐
│                 App 层                       │
│  ┌──────────────┐     ┌──────────────────┐  │
│  │ 主区域播放器  │     │ 全屏播放器       │  │
│  └──────┬───────┘     └────────┬─────────┘  │
├─────────┼──────────────────────┼────────────┤
│         │    Preview Engine   │            │
│  ┌──────▼──────────────────────▼─────────┐  │
│  │         VideoEngine (ffmpeg)          │  │
│  │  - 逐帧解码 (video pipe)              │  │
│  │  - 音频管线 (rodio PCM 输出)          │  │
│  │  - 音频时钟同步                       │  │
│  └──────────────────────────────────────┘  │
├─────────────────────────────────────────────┤
│  AudioEngine (独立于窗口)                   │
│  - 全屏切换不中断音频                       │
└─────────────────────────────────────────────┘
```

### 功能特性

| 功能 | 说明 |
|------|------|
| 播放/暂停 | 空格键控制 |
| 时间线拖拽 | 精确跳转 |
| 倍速播放 | 0.5× – 2×，音调保持 |
| 音量控制 | 滑块 + 静音切换 |
| 音画同步 | 走音频时钟 |
| 截图采集 | 当前帧截图入库 |

### 音频引擎设计

- **独立于窗口**：全屏切换时不中断音频
- **单一 sink**：所有窗口共享同一音频输出
- **ffmpeg 解码**：44.1 kHz 立体声 PCM 输出
- **rodio 播放**：低延迟音频输出

## 3D 模型预览

### 支持的格式

| 格式 | 解析方式 | 备注 |
|------|---------|------|
| OBJ | 自研解析器 | 标准网格 |
| STL | 自研解析器 | 3D 打印格式 |
| PLY | 自研解析器 | 点云 + 网格 |
| glTF | gltf crate | JSON 描述 |
| GLB | gltf crate | 二进制容器 |
| .blend | Blender 无头导出 | 转 GLB 后预览 |

### GPU 视口

```
┌─────────────────────────────────────────┐
│              wgpu 渲染                  │
│  ┌───────────────────────────────────┐  │
│  │  Lambert + Blinn-Phong 着色       │  │
│  │  眼罩光照 (EDL)                   │  │
│  │  背面剔除 + 补洞                  │  │
│  └───────────────────────────────────┘  │
│  ┌───────────────────────────────────┐  │
│  │  交互：旋转 / 缩放 / 平移          │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

### 大文件处理

| 技术 | 说明 |
|------|------|
| 流式常驻预算 | 20GB 不 OOM |
| 抽稀采样 | 覆盖度保持 |
| Meshlet 聚类 | 大网格 (≥8192 面) GPU 逐簇剔除 |
| 空间索引 | 可选 `.trovecloud` 离线索引 (9B/点, 60% 体积) |

### 降级策略

- 有 GPU → wgpu 硬件渲染
- 无 GPU → CPU 软件光栅器

## 缩略图缓存

### 存储布局

```
<cache_root>/
└── thumbs/
    └── <sha[:2]>/
        └── <sha>.jpg
```

### 缓存策略

- 纯内容派生 → 安全删除重建
- 按 SHA-256 分桶 → 避免单目录文件过多
- 导入时检查缓存 → 跳过已存在

### 缩略图类型

| 资产类型 | 生成方式 |
|---------|---------|
| 图片 | 降采样至 512px |
| 视频 | ffmpeg 提取海报帧 |
| 字体 | 渲染样张卡片 (512×256) |
| 3D | 渲染模型正交视图 |

## 截图采集

### 采集方式

| 后端 | 平台 | 优先级 |
|------|------|--------|
| KWin D-Bus | Linux (KDE) | 1 |
| xcap | 跨平台 | 2 |
| grim + slurp | Linux (Wayland) | 3 |
| scrot | Linux (X11) | 4 |
| screencapture | macOS | 1 |

### 采集模式

- **区域截图**：拖拽框选
- **窗口截图**：从窗口列表选择
- **结果**：直接入库为 PNG 资产
