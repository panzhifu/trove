# 2026-09-12

## explorer 面板：添加按钮对齐 + 智能子集合

用户要求：让「下面」的添加符号（智能收藏夹分组标题里的 `+`）和「上面」的（面板标题栏 `+`）对齐，并让它支持智能子集合。

### 对齐（纯布局）
- dock 的 `title_suffix` 外面套 `px_2` 盒子、后面还跟一个 `gap_1` 再才是（空的）toolbar 槽 → 标题栏 `+` 右缘距面板右缘 **12px**；面板内容自己 `p_1`（4px）+ 行 `px_2`（8px）也是 12px，所以行内数字本来就和标题栏对齐。
- 分组标题在 `p_1` 里，只差 8px：`smart_section_header` 加 `.pr(px(HEADER_ACTION_PAD))`（=8），常量 `ROW_PAD=8.` / `ROW_INDENT=14.` / `HEADER_ACTION_PAD=8.` 集中在 `explorer.rs` 顶部「Layout metrics」段，注释里写死了 12px 的来源（改 dock 皮肤要跟着改）。
- `collection_row` 的 `pl(px(22.))` 改成 `pl(px(ROW_PAD + ROW_INDENT))`，与智能行的缩进同一步长。

### 智能子集合（core 早已支持，这次接 UI）
- core 侧 `smart_collections::{parent_id, move_to}` + `Library::move_smart_collection` + 导出/导入的层级还原都已存在（未提交），但 UI 一直传 `parent_id: None` 且平铺渲染。
- `explorer.rs`：
  - 新增纯函数 `nest_order(entries: &[(Uuid, Option<Uuid>)]) -> Vec<(usize, usize)>`（预序 + 深度，防环，成环者兜底平铺列出），`flat_smart_rows` 只负责查计数；`SmartRow` 增加 `depth`。
  - 行的缩进用 **padding**（`.pl`），不是 margin：行是 `w_full`，margin 会把计数挤出面板（tags_panel 里踩过）。
  - `SmartDrag` 拖拽（`common.rs` 新增 payload）：拖到别的智能行 = 嵌进去（`reparent_smart`），拖到分组标题 = 回到顶层；右键菜单加「在其中新建智能收藏夹」「移到顶层」（仅嵌套行显示）。
  - 分组标题的 `+` 现在以 `active_smart` 为父级（同收藏夹 `+` 用 `current_collection`），tooltip 随状态在「新建智能集合 / 在其中新建智能收藏夹」之间切换。
- `rules.rs`：`open_rule_editor(..., parent: Option<Uuid>)`，`RuleDraft.parent`；`save_draft` 用它当 `parent_id`、按同级数量算 `position`，新建后 `select_smart` 选中它（编辑不动视图）。
- 新 i18n 键：`explorer.new_smart_inside` / `explorer.move_to_top`（en/zh 同键同序，已校验 463 键一致）。
