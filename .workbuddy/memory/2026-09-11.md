## 三个 P2 功能（00e4467 / a481924 / a8df908）

### AVIF / JPEG-XL 缩略图
- **JPEG-XL 零成本**：`jxl-oxide 0.12.6` 早就在依赖树里（rawler 的传递依赖），加为直接依赖 + `features = ["image"]` 即可，API 是 `jxl_oxide::integration::JxlDecoder::new(File)` → `DynamicImage::from_decoder`。
- **AVIF 没有纯 Rust 解码器**（没有成熟的纯 Rust AV1 decoder）。`image` 的 `avif` feature 只是 ravif 编码器，解码要 `avif-native` → dav1d（C，要 meson/ninja/nasm，三平台 CI 风险大）。**最终复用 HEIC 那条路**：AVIF 就是 ISOBMFF + AV1 payload，`heif-dec` 能读（本机实测 libheif 带 AV1），所以把 `heic_to_image` 改名 `heif_to_image` 一起用；libheif 没编 AV1 时自然降级为「无缩略图」。
- `probe.rs` 补了 `jxl` 的 kind（原来 `.jxl` 会被归成 Other）和 mime `image/jxl`；尺寸探测走 `JxlImage::open_with_defaults(path).width()/height()`（只读 header）。
- 测试：`ffmpeg -c:v libjxl` / `-c:v libaom-av1 -still-picture 1` 现场造样本（本机 ffmpeg 都有），缺工具就 skip。

### 复制图片到剪贴板
- 用 `arboard 3.6`，开了 `wayland-data-control`（上游非默认，Wayland 下优先于 X11；不支持的混成器仍走 XWayland）。
- **关键坑**：X11/Wayland 下剪贴板数据**由写入进程持有**，谁复制谁hosting，`Clipboard` 一 drop 内容就没了。所以 `library/clipboard.rs` 里用一个 `OnceLock<Mutex<Option<Clipboard>>>` 常驻整个会话，而不是 `set_image` 后丢掉。
- 大图按 `MAX_EDGE = 4096` 缩边再进剪贴板（RGBA raw，arboard 自己转平台格式）。
- 默认键位刻意用 **ctrl-shift-c 而不是 ctrl-c**：ctrl-c 会抢掉搜索框/内联编辑器的文本复制（同一 key context）。
- 右键菜单只对 `AssetKind::Image` 显示；代码里 `Cell` 加了 `day` 字段那套之外，controller 新增 `asset_file()` / `primary_image_file()`（顺带可被 `model_source` 复用）。

### 时间线视图
- `ViewMode` 加 `Timeline`，工具栏按钮变三态循环 Grid→List→Timeline（图标 `IconName::Calendar`，gpui-kit 有 calendar.svg）。
- `Row` 加 `header: Option<String>`：标题行就是「没有 cells 的行」，高度固定 34px，渲染时 `row.header` 有值就画标题，不用改虚拟化结构。
- `timeline_rows()`：按 `day` 降序稳定排序 → 连续同 day 分组 → 每组「标题行 + 自己的 justify 布局」。**注意 `refill_rows` 那条路径对 Timeline 要整组重建**，不能复用来冻结行形状。
- **必须同步改键盘导航**：标题行 cells 为空，原来的 `rows[r-1].cells.len() - 1` 会**下溢 panic**，Up/Down 落到标题行会静默失效。新增 `prev_cell_row()` / `next_cell_row()` 跳过无 cell 的行。

### 踩坑：workspace.rs 里 `#[cfg(test)] mod tests { use super::* }` 会报 "recursion limit reached while expanding #[test]"
- 原因是 `use super::*` 把 gpui prelude 里的 `test` **属性宏**一起 glob 进来了，和标准 `#[test]` 冲突无限展开。
- 解法：测试模块里**显式导入**需要的项（`use super::{Cell, Row, ...}`），不要 glob。gpu3d.rs 能用 glob 是因为那个模块没引 gpui 的 prelude。
