## 项目通读（trove）

- 定位：Eagle 风格的本地数字资产管理工具。Rust workspace，edition 2024。
- 技术栈：GPUI + gpui-component（UI）、libSQL（元数据）、wasmtime + WIT 组件模型（插件）、静态分发 trait（零 dyn）。
- 当前进度：M0 骨架阶段。850 行 Rust，`src/main.rs` 是演示入口（打印库/哈希/评分/ID），不是真应用。
- 已有 crate：`trove-core`（数据模型 + libSQL schema）、`trove-plugin-api`（WIT + 宿主 trait + 共享类型）。
- 待建 crate：`trove-plugin-host`、`trove-ui`、`plugins/*`（文档已规划，代码未写）。
- 三条架构铁律：core 不依赖 GPUI；插件只依赖 plugin-api；插件不链接进主程序。
- 里程碑：M0 骨架 → M1 资产仓库核心 → M2 格式插件管线 → M3 GPUI 界面 → M4 动作插件。
- 测试：`cargo test --workspace` 全绿（core 5 个 + plugin-api 1 个）。
- 构建坑（环境相关，非项目问题）：
  - 沙箱里 HOME 默认 `/root`，cargo 报 `could not create home directory`。须设 `HOME=/home/noke CARGO_HOME=/home/noke/.cargo RUSTUP_HOME=/home/noke/.rustup`。
  - 沙箱把 `/tmp` 挂成 10M tmpfs，libsql 的 `sqlite3.c` 编译会 `No space left on device`。须设 `TMPDIR=/home/noke/.cache/tmp`。
