## 三维模型预览（同日，Phase 3 收尾）

用户两次改向：3D 预览不做检查器视频预览，**不做独立窗口**，改为**点击 3D 模型直接把主面板区域交给视口渲染**（其他资产隐藏），后端用 GPU。

### Core（trove-core）
- 新增 `media/mesh.rs`：OBJ / STL（二进制 + ASCII）/ PLY 统一解析成 `Mesh { positions, triangles, normals?, bounds }`，`is_model_ext`，截断或非网格文件直接报错不半读。
- 新增 `media/render3d.rs`：CPU 光栅化器。`Camera{yaw,pitch,zoom}`（`MAX_PITCH=1.45`、`MIN_ZOOM=0.35`/`MAX_ZOOM=8.0`）、`render(mesh, camera, w, h, supersample) -> Frame{BGRA}`、`auto_size`、`clamp_edge`。双面 Lambert + Blinn-Phong，key light 固定在模型空间（转模型时明暗跟着变）；`Framing`（`to_unit/to_view/to_screen/depth_range/view_projection`）与 `VertexData`（`STRIDE=24`，interleaved `[pos,normal]`，有法线走 indexed、没法线展开成 face normal）是 CPU/GPU 共用层。
- 新增 `media/gpu.rs`：`Uniforms`（176B = mat4 + 7×vec4）与 WGSL 逐字段同序、`padded_row_bytes`（256 对齐）、`unpack_bgra`（去 padding + RGBA→BGRA + alpha 置 255）。这些不碰设备，所以无 GPU 机器也能单测（6 个）。
- `AssetKind::Model` 全链路：probe（mime `model/obj|stl|ply`）、`store::{assets,smart,stats,mod}`（counts 变 `[u64;8]`，kind_index 6）、`thumb::write_model_card`（512×384，supersample 2，BGRA→RGB 存 JPEG）、`maintenance::plan_thumbnail_rebuild` 加 Model。
- **矩阵转置坑（真 bug）**：`view_projection()` 一度把列写成 `[x,y,w,z]`，clip 向量必须是 `(x,y,z,w)`；症状是 ndc_z 爆到 7.8e4（w≈0），画面全黑。已加属性测试和 CPU 投影逐角度比对。

### App（trove-app）
- 新增 `library/gpu3d.rs` + `gpu3d.wgsl`：**自建 wgpu 设备**（gpui 的 device 是私有的，`Window::gpu_specs` 只给描述）。Vulkan|GL 后端，拒绝 `DeviceType::Cpu` 适配器（软件光栅比 CPU 路径还慢），4× MSAA（按 `get_texture_format_features().flags.sample_count_supported` 探测，退 2 再退 1）。离屏 color(Rgba8Unorm) + depth(Depth32Float) + staging(MAP_READ)，`copy_texture_to_buffer` → `map_async` → `poll(wait_indefinitely())` → `unpack_bgra`。
- 新增 `library/viewport3d.rs`：`ModelViewport` entity。**后台线程逐帧渲染**（wgpu handle 在 native 上是 Send+Sync，但 readback 会阻塞；百万面网格阻塞 UI 线程就白用 GPU 了）。用 `dirty` + `in_flight` 合并相机抖动，不排队。GPU 失败（起不来 or 中途失联）自动降级 CPU 并在状态栏说明。工具栏：名称 / 三角面 / 顶点 / 帧耗时 / 采样数 / 适配器 / 重置 / 返回。
- `panels/workspace.rs`：`viewport: Option<Entity<ModelViewport>>`；**视口打开时直接提前 return，网格根本不构建**（查询与行布局都跳过）；Enter 或双击（grid cell 与 list row 都有）进入，Esc 或返回按钮退出。
- **Esc 复用**：`ClearSelection` 已经绑了 workspace 的 escape，不能重复绑。做法是在 WorkspacePanel 的 `ClearSelection` handler 里判断「有视口就关视口并 `stop_propagation()`，否则什么都不做让事件冒泡到 app root 继续清选择」。

### 两个易漏的正确性问题
- **atlas 释放**：视口关闭/被替换时必须把帧 `window.drop_image` 还回去（gpui atlas 永不淘汰）。所以 `ModelViewport::release(window)` 在**所有能拿到 Window 的路径**里调用：工具栏关闭按钮、Esc（面板 side）、新模型替换旧模型。
- **宽高比**：帧尺寸超过渲染器上限时要**整体等比缩放**，分别 clamp 两条边会改掉算 framing 用的 aspect，模型会被拉长。
- `CursorStyle::Grabbing` 不存在，gpui 里是 `ClosedHand` / `OpenHand`。
- `on_prepaint` 属于 `ElementExt`，只挂在 `Div` 上，必须在 `.id()` 之前调用（`.id()` 之后变 `Stateful<Div>`）。
- `Bounds` 名字冲突：本项目的 `trove_core::media::mesh::Bounds` 会遮住 gpui 的 `Bounds`，要 `as MeshBounds`。
- wgpu 29 API 与旧版差异：`PipelineLayoutDescriptor` 无 `push_constant_ranges`（改 `immediate_size: 0`）、`bind_group_layouts` 是 `&[Option<&BindGroupLayout>]`、`DepthStencilState` 的 `depth_write_enabled`/`depth_compare` 是 `Option<_>`（不写不测就传 `None`）。
- **WGSL 无 GPU 校验法**：把 `naga = { version = "29", features = ["wgsl-in"] }` 加进 trove-app 的 dev-dependencies，测试里 `naga::front::wgsl::parse_str` + `Validator` 校验，并用 `naga::proc::Layouter` 断言 uniform 结构体各成员 offset 与 Rust `to_bytes` 完全一致（0/64/80/96/112/128/144/160，总 176，align 16）。这是唯一能在无 GPU 机器上抓住「shader 与 Rust 字节布局不一致」的手段。
