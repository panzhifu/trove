## 三维轴实现落地（commit 145942f）
- **角落 trihedron 画在 UI 层（gpui canvas + paint_path）而不是渲染器里**——一份实现同时覆盖 GPU/CPU 两条渲染路径，字标是 gpui 原生文本（窗口分辨率），且天然是"清过深度的覆盖层"。几何 = 用 `Framing.right/up` 投影世界轴到屏幕（不归一化，垂直屏幕的轴缩成点，同 CloudCompare 正交表现），按 `dot(axis, forward)` 降序画实现远挡近。字标位置 = 端点 + 单位方向 × 8px + 固定 (−4,−6) 居中偏移（近似字体度量）。
- 场景轴（axis_triangles，贴包围盒）从 `height_color` 解耦为独立开关 `scene_axes`（默认开）；角落轴 `corner_axis`（默认开）。都是 AppConfig `Option<bool>` + 画布左上角按钮组持久化。快捷键提示移到画布左下角。
- 渲染后端描述（GPU 适配器/CPU 原因/流式进度）从主面板标题栏迁到状态栏：viewport `backend_text()` → panel observe（文本变化才 notify）→ AppView observe（再比较一次才 notify）——两次去重保证拖动每帧只付一次字符串比较，不重渲染 AppView。标题栏剩几何统计 + frame_ms + reset/close，腾给以后的工具。
- 坑：`gpui::Path` 是泛型 `Path<Pixels>`；`IconName` 完整目录在 `gpui_kit::assets::IconName`（component::IconName 只是兼容子集），命名转换是 kebab→Pascal 且后续段不整词大写（`axis-3d` → `Axis3d`）；`Entity` 被 move 进闭包后不能再 read，要先取出需要的值或先 clone。
