# Trove

> 一个本地、私有的素材库 —— 把图片、文档、音视频统一收纳，可搜索、可打标签、可智能筛选。数据完全留在本机。

Trove 是一个用 Rust 构建的桌面端素材管理工具。界面基于 **[gpui-kit]**，数据持久化使用 **[rusqlite]**（SQLite）。文件以内容寻址方式存储，无论被归入多少个文件夹或标签，同一文件在磁盘上只保存一份。

[English README](./README.md)

## 快速开始

```sh
git clone https://github.com/panzhifu/trove.git && cd trove
cargo run -p trove-app
```

首次启动会在平台标准配置目录下创建素材库。打开标题栏的 **Settings** 可修改素材库位置。

## 功能特性

### 资产导入
- 支持把文件拖入窗口，或通过系统对话框选择文件导入。
- 内容寻址存储：相同文件自动去重。
- 导入时自动识别类型并提取元数据：尺寸、时长、主色调等。
- **智能收藏夹自动捕获匹配资产** —— 无需手动归类。

### 收藏夹与树形导航
- 支持嵌套的收藏夹树，资产与收藏夹是多对多关系。
- 移动文件夹时会检测环，避免形成循环依赖。
- 删除父文件夹会级联删除子文件夹。

### 资产类型
- 图片、视频、音频、文档、压缩包、**字体**（ttf/otf/ttc/woff）等类型，网格中按类型显示图标。
- 导入时挖掘元数据：EXIF、音频标签与时长、字体族/样式/字重、MP4 尺寸与时长；系统装有 `ffmpeg` 时自动生成视频封面。

### 批量操作
- Ctrl/Cmd+点击或 Shift 范围选择；浮动工具栏提供收藏 / 加入收藏夹 / 移入回收站 / 清除。

### 标签、收藏与评分
- 标签不区分大小写，可附加到任意资产。
- 一键收藏，以及 1–5 星评分。

### 全文搜索 (FTS)
- 基于标题和描述的全文搜索（带相关性排序），并可与任意筛选条件组合。
- 特殊字符会被安全地按字面处理，不会导致崩溃。
- 提供重建索引的维护命令，迁移后可按需重建。

### 视觉搜索 (v0.2)
- **以图搜图**：通过感知哈希 + 颜色直方图找到视觉相似的图片。
- **按颜色搜索**：找到包含指定颜色的图片（如 `#ff8000`）。
- 视觉签名在导入后后台计算 —— 不拖慢导入速度。

### 语义搜索（CLIP，可选）
- 以文搜图融入同一个搜索框：关键词（FTS）结果在前，CLIP 语义命中追加其后（自动去重）。
- 视觉搜索面板支持基于 CLIP 向量的以图搜图。
- 导入后自动计算向量；存量图片可在 设置 ▸ 搜索 ▸ 嵌入所有图片 一键补齐。
- 前置条件（手动下载，路径见 设置 ▸ 搜索）：ONNX Runtime 动态库、CLIP ViT-B/32 ONNX 模型（`model.onnx`）及配套 BPE 词表（`bpe_simple_vocab_16e6.txt`），放入模型目录。
- 模型以英文 caption 训练，英文查询效果明显优于其他语言。

### 智能收藏夹
- 基于规则的虚拟文件夹，用 JSON 查询树描述。
- 支持按评分、类型、文本、标签、收藏、颜色匹配，可用 `and` / `or` 组合。
- 查询树在编译期即校验，结果支持分页。

### 回收站与清理
- 删除的资产进入回收站，可随时恢复。
- 清空回收站会释放底层 blob 文件与缩略图。
- 孤儿清理会移除不再被任何资产引用的 blob 文件。

### 拖放
- 从文件管理器拖文件到窗口即可导入。
- 在左侧导航中把资产拖到收藏夹或回收站。
- 把资产拖到标签上可批量打标。
- Ctrl/Cmd+点击多选；拖拽移动整个选区。

### 右键菜单
- 资产：收藏、色标、在文件管理器中显示、加入收藏夹、移入回收站 / 恢复 / 永久删除。
- 收藏夹：新建子收藏夹、重命名、删除。
- 标签：按标签筛选、删除。
- 智能收藏夹：删除。
- 行内编辑：通过回车确认的编辑器添加/重命名收藏夹。

### 检查器
- 缩略图预览，高度根据图片宽高比动态调整。
- 标签与提取的色板。
- 行内编辑：标题、描述、来源链接、类型与 1–5 星评分——失焦/回车或点击即保存。
- 属性：MIME 类型、大小、尺寸、添加日期、SHA-256，一键在文件管理器中显示源文件。
- 可直接添加或移除标签。

### 收集入口
- **粘贴导入**（Ctrl+Shift+V）：剪贴板里的图片直接进入素材库。
- **监视文件夹**：设置 ▸ 通用 中添加监视目录，其下新增的文件自动入库（不归入收藏夹）。首次遇见的目录只做基线标记，不会把已有文件整批导入。

### 色标与重复文件查找
- 资产**色标**（红…紫）可在检查器与右键菜单设置，并可用智能集合的 `color_label` 字段筛选（含"无色标"）。
- **查找重复文件**（文件菜单）：按感知哈希（汉明距离 ≤ 8/64）聚类视觉相同的图片，支持每组"保留最新、其余入回收站"。

### 库安全与管理
- **自动备份**：打开库时通过 SQLite `VACUUM INTO` 快照到 `backups/`（每天至多一次，滚动保留 10 份）；维护页可随时手动备份。
- **最近使用的库**一键热切换，**统计**面板实时展示各类型数量、总容量、标签与集合数。

### 效率工具（P1）
- **批量重命名**：`{n}` 序号 / `{name}` 原名模板 + 实时预览，整批一次撤销。
- **层级标签**：标签可嵌套，筛选/计数/智能集合自动包含子树，删除父标签时子级晋升。
- **库还原**：文件 ▸ 导入素材库… 从导出 JSON 重建收藏夹/标签/智能收藏夹；资产按内容哈希回链，缺媒体的成为占位、重导入时自动补全。
- **本地采集服务**：`http://127.0.0.1:23916` 接收 `POST /add`（原始字节）与 `POST /fetch`（服务端抓取），采集文件自动入库并记录来源 URL（浏览器扩展可直连）。

### 设计格式、文件夹与可移植性
- **SVG 与 PSD 缩略图**：SVG 按矢量渲染（系统字体可显示文字），PSD 合成内嵌预览；导入时挖掘尺寸。
- **相机 RAW 与 HEIC**：CR2/CR3/NEF/ARW/DNG/RAF/ORF/RW2 等经 rawler 管线解码（去马赛克 → 白平衡 → sRGB，自动校正方向）；HEIC/HEIF 在系统装有 heif-dec 时自动转换。
- **文件夹面板**：导入记录来源路径，左栏可按文件夹树浏览并筛选任意子树。
- **媒体包**：文件 ▸ 导出媒体包… 输出可移植目录（元数据 + blob）；导入素材库… 同时接受 JSON 导出与目录包，按内容哈希自动回链。
- **浏览器扩展**：`extension/` 内置 MV3 扩展，右键即可把网页图片发送到运行中的 Trove。

### 界面语言
- 支持英文与简体中文，设置 ▸ 语言实时切换；默认跟随系统语言。

### 配置
- 配置以 JSON 保存在平台标准配置目录。
- 可在设置对话框中修改素材库所在位置。

## 界面布局

![Trove 主窗口](docs/screenshots/main-window.png)

桌面应用采用停靠栏（dock）布局，配自定义标题栏：

| 停靠位置 | 面板 | 用途 |
|----------|------|------|
| 顶 | 标题栏 | File / Settings 按钮、窗口控制 |
| 左 | 资源管理器 | 收藏夹树、智能收藏夹、回收站 |
| 中 | 工作区 | 对齐缩略图网格 + 搜索 |
| 右 | 标签 + 检查器 | 标签筛选与资产详情 |

- **File** 菜单导入文件；**Settings** 打开素材库路径设置。
- 整窗都可以作为拖放目标，直接把文件拖入即可导入。
- 工作区网格采用对齐布局（Google 相册风格），任意宽度下都撑满面板、不留空白。
- 工作区标题栏内嵌弹出式搜索框，旁边显示当前视图的资产数量。

## 项目结构

```
crates/
├── trove-core/          # 领域、持久化与服务层（无 UI）
│   ├── src/
│   │   ├── model.rs     # 纯数据类型 (Asset, Collection, Tag, …)
│   │   ├── library.rs   # 对 store + 媒体目录的高级封装
│   │   ├── services/    # 备份（VACUUM INTO）、维护任务、采集服务
│   │   ├── layout.rs    # 对齐网格布局（动态规划）
│   │   ├── store/       # SQLite 层：schema, CRUD, FTS, 智能查询, 统计
│   │   ├── media/       # 导入、探测、缩略图、颜色、视觉/CLIP 语义搜索
│   │   ├── maintenance.rs # 重建缩略图/索引、孤儿清理
│   │   ├── undo.rs      # 撤销/重做操作日志
│   │   ├── events.rs    # 跨层事件
│   │   ├── config.rs    # 应用配置持久化 (JSON)
│   │   └── error.rs     # 错误类型
└── trove-app/           # gpui-kit 桌面 UI
    ├── src/
    │   ├── main.rs       # GPUI 引导、菜单、快捷键
    │   ├── app/          # 窗口壳层：根视图、标题栏、动作、i18n
    │   ├── library/      # LibraryController、导入任务、文件夹监听
    │   ├── dialogs/      # 设置、规则编辑器、重复文件查找、批量重命名
    │   └── panels/       # 资源管理器、文件夹、工作区、标签、检查器
    └── Cargo.toml
```

核心数据表：

```
assets             # 资产记录
collections        # 嵌套文件夹
asset_collection   # 资产-收藏夹多对多
tags               # 标签（不区分大小写）
asset_tag          # 资产-标签关联
smart_collections  # 智能收藏夹（规则过滤）
asset_fts          # 全文搜索索引
```

磁盘上的素材库结构：

```
<root>/
├── library.db      # 单文件数据库
└── media/…         # 内容寻址的文件
```
